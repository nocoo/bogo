## Project Invariants

- Browser: `bogo.hexly.ai` (Cloudflare Access). CLI API: `api.bogo.hexly.ai` (no Access app). Login/consent stays on `bogo.hexly.ai/api/auth/cli`. Do not put a CF Access Bypass on `Authorization`.
- `clip.yaml` `loginUrl` must be the Access host; `baseUrl` the API host. CLI source is generated by [clip](https://github.com/nocoo/clip); this repo does not hand-edit generated CLI source.
- Vite :7036 (`https://bogo.dev.hexly.ai`) proxies `/api` to local wrangler :37036, not prod. localhost / `*.dev.hexly.ai` skip Access JWT.
- `bun run seed:local` writes gitignored `.wrangler/` only. Never `--remote`.
- E2E is `--local --persist-to` only. L2 `.wrangler/e2e` :17036; L3 `.wrangler/e2e-pw` :27036; CLI e2e uses its own persist dir. Do not use 8787.
- `bun run deploy` races CD. Version with `bun scripts/bump-version.ts`; Worker deploys via `.github/workflows/release.yml`.
- `gate:routes` is a static `(method, path)` scan vs e2e files — structural hit, not assertion quality.
