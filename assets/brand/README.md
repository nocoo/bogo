# Bogo identity

The selected Bogo 05 portrait keeps natural buffalo anatomy, a wink, and one rainbow flower sprig. Connected walnut and gold facets sit on a warm mineral field with shallow angular arches. The animal enters through the bottom and lower-right edges; the face, horns, ears, and complete sprig stay at least 128 pixels inside the 2048-pixel rounded tile.

- `logo.png` is the transparent 2048 × 2048 master.
- `assets/brand/icon.png` is the square tile for platform-managed masking.
- `assets/brand/icon-rounded.png` supplies rounded corners for the README and app surfaces.

Run `uv run --with pillow python scripts/resize-logos.py` to regenerate the sidebar, display, and PNG favicon assets. The generator checks master dimensions and their square/rounded alpha roles. Bogo uses a PNG favicon, without an ICO container.

The owner approved the exact raw image and authorized local finishing and source replacement. The entire approved drawing is uniformly scaled to 80%. Small independently archived vector facets complete the native ear/horn crop and the lower-right shoulder; no neck stretching or edge-row repetition is used. Every fully opaque placed source pixel is verified unchanged. The source PNG, intermediate passes, palette evidence, and layer checksums remain in the hexly.ai workshop.
